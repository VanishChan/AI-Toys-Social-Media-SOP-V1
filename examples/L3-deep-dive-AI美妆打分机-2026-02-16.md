## L3-001（L2-003）高眼位/低眼位适配
- 开场钩子：`你到底适合高眼位还是低眼位？10秒给你答案`
- 冲突结构：同一张脸两种画法差异大，用户常选错。
- 解决动作：AI先打分 -> 判定眼位倾向 -> 给2条修改建议。
- 结果展示：修改前后对比 + 分数变化。
- CTA：`评论区发素颜/半妆图关键词，我给你做同款判定模板。`
- AI改写位：第2秒出分；第8秒给建议；第18秒复评。

## L3-002（L2-004）新手遮黑眼圈
- 开场钩子：`黑眼圈越遮越灰？你可能错在这一步`
- 冲突结构：新手遮瑕顺序错误，妆感脏。
- 解决动作：AI识别眼下区域 -> 给色号/手法建议 -> 1步修正。
- 结果展示：局部特写前后 + 全脸协调分。
- CTA：`想要“眼下不脏”模板，评论区扣1。`
- AI改写位：第3秒局部评分；第10秒动作指令；第22秒复评分。

## L3-003（L2-009）心动狙击妆妆教
- 开场钩子：`这套妆为什么“看着贵”？AI给你拆开看`
- 冲突结构：用户知道好看但不知道“好看在哪里”。
- 解决动作：AI分维度打分（眼妆/唇妆/轮廓）-> 给优先优化项。
- 结果展示：先改1个关键位，拉高整体风格分。
- CTA：`下一期拆“氛围感妆”，想看扣“氛围”。`
- AI改写位：第1秒总分；第7秒分项雷达；第20秒复评。

## L3-004（L2-001）红唇妆
- 开场钩子：`同样红唇，为什么你显凶她显贵？`
- 冲突结构：色号与脸型/肤色不匹配，导致气质偏差。
- 解决动作：AI识别唇形与肤色 -> 推荐红唇方向与边缘处理。
- 结果展示：唇部局部对比 + 全脸风格匹配分。
- CTA：`要我做“你的红唇方向”，评论发“红唇”。`
- AI改写位：第2秒匹配分；第9秒改法；第17秒二次评分。

## L3-005（L2-002）仿妆类
- 开场钩子：`你不是画不像，是方法顺序反了`
- 冲突结构：仿妆失败多为结构错位，不是技术差。
- 解决动作：AI先识别目标风格关键词 -> 给三步对齐路径。
- 结果展示：从“像一点”到“像很多”的分数跃迁。
- CTA：`下一条做“你像哪位风格”，留言目标女明星/博主。`
- AI改写位：第3秒风格相似度；第12秒三步方案；第24秒复评。

## L3-006（L2-006）修容
- 开场钩子：`修容显脏不是手残，是位置错了`
- 冲突结构：多数人按教程画，但脸型不适配。
- 解决动作：AI判定脸型 -> 给“减法修容”线路图。
- 结果展示：前后轮廓干净度分 + 面中立体度分。
- CTA：`想要你的脸型修容线，评论“脸型”。`
- AI改写位：第2秒脸型识别；第8秒线路图；第19秒复评。

## L3-007（L2-007）过程型（cos妆）
- 开场钩子：`半路翻车怎么救？AI实时纠错`
- 冲突结构：过程里容易出现“越画越偏题”。
- 解决动作：中途打分 -> 偏差预警 -> 给“返正”动作。
- 结果展示：从偏题到回正的过程分数曲线。
- CTA：`做一期“妆面翻车急救包”，想看扣“急救”。`
- AI改写位：第5秒中途评分；第13秒纠偏；第25秒终评。

## L3-008（L2-010）眼部护理转美妆表达
- 开场钩子：`眼周状态不对，再贵眼妆也出不来`
- 冲突结构：用户把护肤与妆效割裂。
- 解决动作：AI先评眼周状态 -> 给妆前处理建议 -> 再上妆。
- 结果展示：细纹卡粉/暗沉改善前后对比。
- CTA：`要“妆前眼周处理清单”，评论“眼周”。`
- AI改写位：第2秒眼周健康分；第11秒处理步骤；第23秒妆效复评。
