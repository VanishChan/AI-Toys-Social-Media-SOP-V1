# SOCIAL MEDIA SKILL 管理层汇报版

汇报日期：2026-02-17  
范围：数字营销-官方自媒体（小红书主站 + 抖音分发）

## 一、下阶段计划：怎么做、为什么、预期带来什么

### 1. 下阶段怎么做（未来2周）
1. 按“产品-人群-场景”驱动执行，不再固定母婴赛道。
2. 严格执行三层采集：
   - L1榜单证据采集（暴增/低粉/商业）
   - L2快看评分（封面+前5秒+评论信号）
   - L3完整拆解（形成可拍模板）
3. 每周固定产出3条（小红书主发，抖音适配分发）。
4. 每条内容强制采用“先打分-再建议-再复评分”闭环表达。
5. 发布后按 Day1/Day2/Day7 固定复盘，执行模板晋级机制。

### 2. 为什么这样做
1. 过去选题和生产依赖个人经验，稳定性差，无法规模复制。
2. 现阶段目标是先做“可复制增长”，而非单条偶发爆款。
3. 三层采集能把“热点噪音”过滤成“可执行模板”。
4. 1/2/7复盘可把内容迭代从主观判断改成数据驱动。

### 3. 这么做可能带来什么（预期收益）
1. 内容产出效率提升：从“临时组织”转为“流程化周更”。
2. 内容质量稳定：前5秒、标题、建议动作可持续优化。
3. 人力结构优化：人类从重复执行转向策略与决策。
4. 资产沉淀：形成可复用模板库，降低后续起量成本。

## 二、上阶段总结：数据表现与迭代方向

### 1. 上阶段完成情况（阶段性）
1. Social Skill 已完成流程封装与规则固化。
2. 已完成行业映射机制，不再默认单一行业采集。
3. 已完成AI美妆打分机项目的 L1/L2/L3 全链路样例。
4. 已完成首发周生产包（3条脚本+分镜+排期）。
5. 已建立 Day1 复盘样例与三张复盘表模板。

### 2. 上阶段数据表现（当前已知口径）
1. 已形成结构化评估口径：点击、2秒跳出、5秒留存、互动、收藏、评论、转化线索。
2. 初步判断：
   - “方法论+前后对比”结构更适配本SKU转化。
   - 纯粉圈互动内容虽高曝光，但对产品转化价值有限。
3. 当前不足：
   - 真实发布数据样本仍少，模板稳定性需通过连续周验证。

### 3. 我们将如何迭代（下一轮动作）
1. 变量最小化实验：每轮只改1-2个变量（如前5秒钩子/字幕结构）。
2. 分平台精调：小红书与抖音分别优化开场节奏和文案风格。
3. 提升收藏与转化：增加“可截图步骤卡/清单”表达。
4. 模板晋级门槛：
   - 连续2条达标且Day7不衰减 -> Promote
   - 指标波动大 -> Hold
   - 连续2轮修正无改善 -> Discard

## 三、管理层关注的里程碑（建议）
1. 里程碑1（1周）：完成首发3条 + Day1复盘。
2. 里程碑2（2周）：完成6条内容 + 至少1个模板进入Hold/Promote候选。
3. 里程碑3（4周）：形成稳定模板库（>=2个可复用模板）。
