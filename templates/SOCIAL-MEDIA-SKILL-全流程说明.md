# SOCIAL MEDIA SKILL 全流程说明（小红书主站 + 抖音分发）

版本：V1  
适用范围：官方账号内容生产（图文/视频）、榜单选题、模板化迭代、1/2/7复盘

## 1. 这个Skill可以做什么
1. 把“内容选题-制作-发布-复盘”做成标准流程，不靠个人经验拍脑袋。
2. 根据 Brief 里的产品介绍/卖点/人群/场景，自动判定该去新红采哪个行业。
3. 用三层采集（L1/L2/L3）筛出可做内容，并产出脚本和分镜。
4. 为小红书输出主版本，再自动给抖音做分发适配版本。
5. 用 Day1/Day2/Day7 数据复盘，AI给出问题归因和修正动作。
6. 把有效内容升级成可复用模板，不断迭代。

## 2. 输入要求（必须先给Brief）
Brief至少要包含：
1. 产品与卖点：产品介绍、3-5条主要卖点（带证据）。
2. 人群与场景：目标人群、核心场景、人群场景优先级（`>`）。
3. 目标与约束：KPI优先级（`>`）、可公开/不可公开、禁词红线。
4. 渠道与资源：主平台/分发平台、素材资源、制作资源。
5. 新红账号信息：账号、密码、是否允许本轮自动采集。

说明：
- 无新红账号则不能在线采集，只能走离线证据模式（导出表/截图）。

## 3. 流程编排（从立项到复盘）

### 阶段A：准入与行业映射
1. 检查Brief完整性与逻辑冲突。
2. 输出行业映射报告：主行业、次行业、排除行业、判定理由。
3. 未完成行业映射，不进入采集。

### 阶段B：三层采集
1. L1榜单采集：暴增/低粉/商业三榜结构化抓取，形成证据表。
2. L2快看评分：看封面+前5秒+评论信号，做可改造度评分。
3. L3完整拆解：对高分样本做结构拆解，形成可执行模板。

### 阶段C：生产包输出
1. 输出选题池与优先级。
2. 输出脚本、分镜、封面说明、标题候选、植入方式。
3. 输出双平台版本：小红书主版 + 抖音适配版。

### 阶段D：发布与复盘
1. 发布后固定看 Day1/Day2/Day7。
2. 每个节点输出三张表：
   - 数据汇总表
   - AI评估表（问题->原因->动作）
   - 模板迭代日志
3. 给出模板结论：Promote / Hold / Discard。

## 4. AI与人类分工
AI负责：
1. 行业映射与榜单采集逻辑。
2. L2评分与L3结构拆解。
3. 脚本分镜与双平台适配。
4. 复盘归因与下一轮实验建议。

人类负责：
1. 最终拍板（选题、风险、发布）。
2. 实拍/剪辑/设计执行。
3. 发布动作和账号运营。
4. 对AI结论发起挑战并定版。

## 5. 固定产物清单（每轮都应有）
1. Brief检查报告
2. 行业映射报告
3. L1证据表
4. L2评分表
5. L3拆解表
6. 待制作内容表
7. 双平台内容包
8. Day1/2/7复盘三表
9. 模板晋级结论

## 6. 硬规则（不满足就不准出）
1. 无Brief -> 不生产。
2. 无行业映射 -> 不采集。
3. 无L1证据 -> 不出最终选题。
4. 无L2评分 -> 不出待制作清单。
5. 无L3拆解 -> 不出最终脚本模板。
6. 无Day1/2/7复盘记录 -> 不做模板晋级。

## 7. 给新成员的最短上手路径
1. 按模板填Brief（10-15分钟）。
2. 跑行业映射并确认采集行业（5分钟）。
3. 跑L1-L2-L3（60-120分钟，视样本量）。
4. 输出本周3条生产包并排期（30分钟）。
5. 发布后按Day1/2/7复盘并迭代（每次15-30分钟）。
