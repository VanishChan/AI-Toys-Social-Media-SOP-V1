# SOCIAL MEDIA SKILL 一页操作卡

适用：小红书主站 + 抖音分发（统一内容生产）  
目标：用标准化流程持续产出可复用爆款模板

## 1. 开始前（必须提供）
1. Brief（产品介绍、卖点、受众、场景、KPI排序）
2. 新红账号/密码（在线采集）  
3. 可公开/不可公开边界与禁词
4. 素材与制作资源（拍摄/剪辑/设计）

## 2. 四阶段流程
1. 准入：检查Brief完整性，做行业映射（主行业/次行业）
2. 采集：三层采集 L1/L2/L3
3. 生产：输出脚本分镜与双平台版本
4. 复盘：Day1/Day2/Day7，决定Promote/Hold/Discard

## 3. 三层采集（核心）
1. L1：榜单证据采集  
说明：暴增/低粉/商业三榜，先拿证据不下结论
2. L2：快看评分  
说明：封面 + 前5秒 + 评论信号，评估可改造度
3. L3：完整拆解  
说明：拆开场、冲突、动作、结果、CTA，沉淀模板

## 4. 每轮必须交付
1. 行业映射报告
2. L1证据表
3. L2评分表
4. L3拆解表
5. 待制作清单
6. 双平台内容包（小红书主版 + 抖音适配版）
7. Day1/2/7复盘三表  
说明：数据汇总表 + AI评估表 + 模板迭代日志

## 5. AI与人类分工
1. AI：行业映射、采集分析、评分拆解、脚本建议、复盘诊断
2. 人类：拍板、执行拍摄剪辑、发布运营、风险把关

## 6. 硬红线（不满足即停止）
1. 无Brief：不生产
2. 无行业映射：不采集
3. 无L1：不出最终选题
4. 无L2：不进制作排期
5. 无L3：不出最终脚本模板
6. 无Day1/2/7记录：不做模板晋级

## 7. 每周最简执行节奏
1. 周一：Brief + 行业映射 + L1/L2
2. 周二：L3 + 3条脚本定稿
3. 周三到周六：发布3条
4. 按Day1/2/7复盘并更新模板版本
