# Evidence Gate（选题证据闸门）

## 硬规则
- 没有榜单证据表，不输出“最终选题”。
- 没有L2快看评分表，不输出“待制作内容表”。
- 没有L3完整拆解表，不输出“最终脚本/模板”。
- 允许输出“候选方向”，但必须明确标注为待验证。

## 榜单证据表最小字段
- 榜单类型：暴增 / 低粉爆款 / 商业笔记
- 分类与时间窗口
- 参考笔记链接
- 笔记形式：视频/图文
- 核心钩子与前5秒结构
- 可借鉴点 / 不可借鉴点
- 与SKU匹配分（1-5）

## 输出口径
- 最终选题必须逐条对应至少1条证据记录。
- 最终选题必须同时给出：L1证据ID + L2评分ID + L3拆解ID。
- 若无法登录/抓取榜单，必须先说明限制，再请求：
  - 导出表格
  - 截图
  - 账号侧人工摘录
