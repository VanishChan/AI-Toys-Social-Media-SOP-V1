# Template Evolution（模板化复用规则）

## 1. 模板定义
这里的模板是“已验证有效的内容技法组合”，不是固定文案。
每个模板必须绑定：产品类型 + 人群 + 场景 + 主要卖点。

## 2. 升级规则
- 单条表现达阈值 -> 进入观察池
- 连续2条同技法表现达标 -> 升级为可复用模板

## 3. 复用方式
- 小改动重复发（标题、场景、人物设定微调）
- 保留核心钩子与前5秒结构
- 保持平台合规和描述一致性
- 同模板跨产品复用时，必须重写“卖点证据段”，不能直接沿用。

## 4. 风险控制
- 避免虚假承诺
- 避免侵犯他人素材版权
- 避免“强个人经历”硬套品牌
