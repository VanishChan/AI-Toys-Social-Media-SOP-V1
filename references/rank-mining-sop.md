# Rank Mining SOP（新红榜单挖掘）

## 1. 数据源
- 新红 xh.newrank.cn
- 榜单：暴增笔记、低粉爆款、商业笔记

## 2. 建议顺序
1. 暴增笔记：看近期热点与表现形式
2. 低粉爆款：看以小搏大的内容结构
3. 商业笔记：看可用植入方式

## 3. 统一筛选参数（可按项目调整）
- 一级分类：按“行业映射报告”选择主行业（必要时补次行业）
- 二级分类：默认不选
- 统计周期：周榜 + 月榜
- 排序：互动总数最高
- 样本量：每榜200条

补充：
- 必须记录“本次实际行业选择”与“未选行业原因”。
- 如果主行业数据稀疏，可启用次行业补样，但要单独标记来源行业。

## 4. 筛选规则
- 不可直接照搬强个人属性内容
- 可提取“爆款基因”：话题、结构、表现形式、前5秒钩子
- 若参考是视频，默认输出视频；若参考是图文，默认输出图文

## 5. 三层采集机制（必跑）
### 第一层：榜单结构化采集（机器快筛）
- 目标：先广覆盖抓样本，不主观下结论。
- 范围：三榜各200条（可因权限缩减，但要记录实际条数）。
- 采集字段：标题、形式、作者层级、发布时间、核心互动数据、品牌字段（商业榜）。
- 产出：`L1榜单证据表`。

### 第二层：快看采集（半人工半AI）
- 目标：验证“标题党”与真实内容匹配度。
- 样本：L1中每榜前10-15条，共30条左右。
- 每条至少看：封面、前5秒、评论区高赞前5条。
- 评分：前5秒抓力、内容清晰度、可品牌化改造度、合规风险。
- 产出：`L2快看评分表`（未达阈值不进入L3）。

### 第三层：完整采集（深拆模板）
- 目标：输出可复用脚本模板，而不是泛泛选题。
- 样本：L2总分前10条。
- 每条完整观看并拆解：开场钩子、冲突推进、反转、结尾CTA、产品植入位、镜头节奏。
- 产出：`L3完整拆解表` + `最终选题池` + `脚本骨架`。

## 6. 输出
- 热点表
- 选题表
- 参考表
- 对标内容表
- 待制作内容表
