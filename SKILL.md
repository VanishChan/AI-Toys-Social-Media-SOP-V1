# Social Media SOP (XHS Primary + Douyin Distribution)

## When to use
- Official brand social content production for Xiaohongshu and Douyin.
- Need unified content pipeline, then split output by platform specs.
- Need rank-mining process from Newrank and repeatable template strategy.

## Inputs required (Brief-first)
- SKU and audience segment
- Product intro and USP list (with evidence/demo proof)
- Newrank account/password (for online mining runs)
- Content period (weekly/monthly)
- Priority KPI order (must be ranked with `>`)
- Available production resources (video/image capacity)
- Allowed and forbidden claim boundaries

## Workflow (strict)
1. Validate brief and objective hierarchy.
2. Map product/persona/scenes -> Newrank target category (with explicit rationale).
3. Execute three-layer mining (rank evidence -> quick watch -> full teardown).
4. Layer 1: rank mining (暴增/低粉爆款/商业笔记) with structured evidence table.
5. Layer 2: shortlist quick watch (cover + first 5s + top comments), then score.
6. Layer 3: full watch top candidates and extract reusable script structure.
7. Build 4 tables: 热点/选题/参考/对标 + 待制作清单.
8. Decide content form (image or video) based on source-note format and feasibility.
9. Generate production package:
   - Topic rationale
   - Hook/title/caption candidates
   - Cover instructions + prompts
   - Script + storyboard for video OR image-card outline for graphic posts
   - Product-integration approach
10. Split output for platforms:
   - XHS master version
   - Douyin adapted version (ratio, title tone, caption style, first 5s)
11. Publish and collect metrics at Day1/Day2/Day7 with fixed review tables.
12. AI produces retrospective diagnosis and action list at each node.
13. Decide whether content becomes a reusable template.
14. Iterate template library and replication rules.

## Role split
- AI:
  - Rank-mining summary and candidate filtering
  - Topic extraction and match scoring
  - Form decision support (video vs image)
  - Script/storyboard or graphic outline generation
  - Platform adaptation and metric review
- Human:
  - Final selection and risk control
  - Actual production shooting/editing/design
  - Publish decision and account operation

## Required outputs each run
- Brief check report
- Rank-mining extraction summary
- 4 analysis tables + production backlog
- XHS/Douyin dual-platform content package
- Day1/Day2/Day7 metrics summary table
- AI evaluation table (issue -> cause -> action)
- Template iteration log
- Template promotion decision (promote/hold/discard)

## Hard rules
- No brief -> no production.
- No Newrank credentials -> no online rank mining (must switch to offline evidence mode).
- No category-mapping report -> no rank mining.
- No rank evidence table -> no final topic list.
- No layer-2 quick-watch scores -> no production backlog.
- No layer-3 full teardown -> no final script/template decision.
- No Day1/Day2/Day7 retrospective records -> no template promotion decision.
- Replication allowed, but must keep claim compliance and brand safety.
- If source reference is video, default output should stay video unless clear production blocker.
- First 5 seconds for video should stay close to validated reference logic.
